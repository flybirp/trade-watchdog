# 条件清单契约（trade-buddy ⇄ trade-watchdog）

trade-buddy 产出条件清单，trade-watchdog 消费它。本文件定义两者之间的接口。

**核心结论先说**：没有「观测方式」列，巡检就无法自动化。这一列是契约的成败所在。

---

## 1. 为什么需要「观测方式」

条件清单原本的列是：必要条件 / 类型 / 可观测指标 / 达标阈值 / 观测时点 / 当前状态。

看起来够结构化，但**少了一件事：这个指标到底去哪儿查。**

实测反例（恒生科技指数决策单）：

| 条件 | 可观测指标 | 能自动查吗 | 原因 |
|---|---|---|---|
| 估值修复 ≥27 倍 | 指数 PE(TTM) | **否** | 结构化接口对指数返回 `市盈率: 0.00`，只能靠券商研报 |
| 指数跌破 2720 | 指数点位 | **是** | `kline hkHSTECH` |
| ETF 溢价 >3% | ETF 折溢价率 | **是** | `etf sh513180` |
| 盈利年增 ≥18% | 指数 EPS(TTM) 同比 | **否** | 只有年度口径，来自年报/研报 |
| 美联储不重新加息 | 联邦基金利率路径 | **否** | 需查 FOMC 日历与决议 |

**9 条条件里只有 3 条可自动。** 没有观测方式列，watchdog 只能逐条试错，或者凭描述猜数据源——猜错比不查更糟（比如拿个股 PE 去当指数 PE）。

## 2. 契约：两张表的完整列定义

### 表 A · 达成条件清单

| 列名 | 必填 | 填写规范 |
|---|:--:|---|
| 必要条件 | ✅ | 一句话，动宾结构 |
| 类型 | ✅ | 只能是：业绩 / 估值 / 催化 / 资金 / 技术 / 宏观 |
| 可观测指标 | ✅ | 指标全名，带口径（如「指数 PE(TTM)」不能只写「PE」） |
| 达标阈值 | ✅ | 带单位与方向的数值，或明确的事件口径 |
| **观测方式** | ✅ | **见第 3 节** |
| 观测时点 | ✅ | 具体日期 / 频率（每日、每月、每年 3 月年报、每次 FOMC） |
| 当前状态 | ✅ | 已达成 / 部分达成 / 未达成 |

### 表 B · 阻断条件清单

| 列名 | 必填 | 填写规范 |
|---|:--:|---|
| 阻断条件 | ✅ | 一句话 |
| 为什么会阻断 | ✅ | 传导链：该事件 → 影响什么 → 为何导致目标不成 |
| 可观测指标 | ✅ | 同上 |
| 触发阈值 | ✅ | 同上 |
| **观测方式** | ✅ | **见第 3 节** |
| 观测时点 | ✅ | 同上 |
| 当前状态 | ✅ | 未触发 / 部分触发 / 已触发 |

## 3. 「观测方式」列填写规范（关键）

三种写法，三选一：

### 写法一：可自动 —— 填具体命令

```
westock: kline hkHSTECH --period day --limit 2
westock: etf sh513180
westock: hkfund hk03888
westock: technical hkHSTECH --group ma,macd
futu: snapshot HK.03888
futu: shortvol HK.03888 30
```

规则：
- 格式为 `数据源: 完整命令`，不留歧义
- 命令必须**实际跑通过**，不能是想象中的命令
- 跑不通的不要填这里 —— 填了就是给 watchdog 埋雷

### 写法二：需人工 —— 写明来源与节奏

```
人工: 年报（每年 3 月，港交所披露易）
人工: 券商研报（无稳定接口，季度不定时）
人工: FOMC 决议（每次议息会议，需看新闻）
人工: 减持公告（随时，需看巨潮/披露易）
```

规则：
- 以 `人工:` 开头
- 括号里写清**具体来源**与**查询节奏**
- watchdog 不会去取数，只在观测时点到了时提醒用户去查

### 写法三：不可观测 —— 明说

```
不可观测: 无公开数据源，依赖主观判断
```

诚实标注。这类条件不进巡检，只在人工复核时看。

## 4. 可自动观测性分级（trade-buddy 填写时的自检）

写条件时按这个表判断该填哪种写法：

| 指标类型 | 典型例子 | 可自动？ | 数据源 |
|---|---|---|---|
| 价格 / 点位 | 股价、指数点位、突破某价位 | ✅ | `kline` |
| 成交量额 | 成交额、换手率、量比 | ✅ | `kline` |
| 技术指标 | MA、MACD、BOLL | ✅（港股部分指标为空，见下） | `technical` |
| ETF 溢价 / 规模 | 折溢价率、基金规模、申购状态 | ✅ | `etf` |
| 资金流 | 主力净流入、港股通持股变动 | ✅ | `asfund` / `hkfund` |
| 卖空数据 | 卖空量、空头持仓 | ⚠️ 需 OpenD | `futu_quote.py` |
| 公告事件 | 减持、回购、重大合同 | ⚠️ 半自动 | 公告站 + 检索 |
| 财报数据 | 营收、EPS、利润率 | ❌ 按季度披露 | 年报 / 中报 |
| 指数估值 | 指数 PE / PB 及分位 | ❌ 接口常返回 0 | 券商研报 / 指数公司 |
| 卖方预期 | EPS 一致预期 | ❌ 无稳定接口 | 研报 |
| 宏观 | 利率决议、汇率、政策 | ❌ | 新闻 / 日历 |

**港股技术指标注意**：`technical` 对港股只有 MA / MACD / BOLL / BIAS 有效，KDJ / RSI / WR / DMI / OBV 返回 `-`。**不要用返回 `-` 的指标做条件**，否则 watchdog 永远读到空值。

## 5. 状态四态（watchdog 判定用）

| 状态 | 含义 | 触发报告 |
|---|---|:--:|
| `已达成` / `已触发` | 阈值满足 | ✅ 立即报 |
| `部分达成` | 方向对但未到阈值 | ❌ 静默（除非进缓冲带） |
| `未达成` / `未触发` | 未到阈值 | ❌ 静默 |
| `数据缺失` | 命令失败 / 字段为空 | ✅ 报（要让用户知道查不到） |
| `逼近阈值` | 进入阈值 ±10% 缓冲带 | ✅ 预警 |

**`数据缺失` ≠ `未达成`。** 前者是查不到，后者是查到了没到。混淆会让用户误判。

## 7. 演进约定

契约变更时（加列、改状态名）**必须同时改三处**：

1. `trade-buddy/templates/trade-decision-card.md`
2. `trade-buddy/references/probability-calibration.md`
3. 本文件

老决策单缺列时，watchdog 应提示「该决策单版本较旧，缺『观测方式』列，无法自动巡检」，而不是硬扫。
